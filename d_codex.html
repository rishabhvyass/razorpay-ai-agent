在 Codex 中使用 Agent Router ​

配置参数 ​

配置项填写内容 / 说明
OPENAI_API_KEY你的 AgentRouter Key
OPENAI_BASE_URLhttps://agentrouter.org/v1
OPENAI_MODELgpt-5.6、gpt-5.5、glm-5.2
Base URL 规则OpenAI compatible 配置，Base URL 加上 /v1

安装 Codex CLI ​

  1. 确认 Node.js：Codex CLI 要求 Node.js 18 或更高版本。
bash
node --version
  1. 安装 Codex CLI：使用 pnpm 全局安装官方包（也可以用 npm）。
bash
pnpm install -g @openai/codex
  1. 检查安装结果：确认 codex 命令可用。
bash
codex --version

配置 AgentRouter ​

访问 https://agentrouter.org/console/token ，获取你的 API Key。

创建 ~/.codex/config.toml 文件，并添加如下配置（把 ak-xxxxxxx 换成你自己的 Key）：

toml
model = "gpt-5.5"
model_provider = "agentrouter"

[model_providers.agentrouter]
name = "AgentRouter"
base_url = "https://agentrouter.org/v1"
wire_api = "responses"
experimental_bearer_token = "ak-xxxxxxx"

启动并测试 ​

配置好后，使用终端打开你要操作的项目目录，然后运行如下命令启动 Codex：

bash
# 进入项目目录
cd my-project

# 启动 Codex
codex

先测试连通性：输入 只回复 OK；再测试只读目录能力：输入 列出当前目录下的文件，并说明是否存在 README 文件，不要修改文件。
