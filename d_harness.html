安装配置指南 ​

一、VS Code 插件型 Harness ​

VS Code 插件型 Harness 建议按 Provider / API 协议分两类配置：Claude Opus 系列优先使用 Anthropic + Use custom base URL，Base URL 不加 /v1；其他通用模型使用 OpenAI Compatible，Base URL 加 /v1。两类方法是并行关系，不要混用。

在Cline中使用AgentRouter ​

在VS Code中安装Cline ​

  1. 在 VS Code Extensions 中搜索 Cline 并安装。

  2. 访问 https://agentrouter.org/console/token ，获取你的 API Key

  3. 打开 Cline 面板，进入 Settings / API Configuration。

配置方法一：Claude Opus 系列（推荐优先使用） ​

适用场景：需要在 Cline 中调用 Claude Opus 系列模型。该方法与 OpenAI Compatible 通用流程并行，不要把 Base URL / Provider 混用。

  1. API Provider 选择 Anthropic。

  2. 勾选 Use custom base URL。

  3. Custom Base URL 填写 https://agentrouter.org。注意这里不需要加 /v1。

  4. API Key 填写你获取的 API Key。

  5. Model 默认选择 claude-opus-4-6，也可以选择claude-opus-4-8和claude-opus-4-7

  6. 保存后先发送“只回复 OK”测试连通性，再测试读取当前工作区文件。

配置方法二： OpenAI Compatible ​

适用场景：需要调用 gpt-5.5 和 glm-5.2。

  1. API Provider 选择 OpenAI Compatible，或选择等价的自定义 OpenAI-compatible 选项。

  2. API Key 填写你的 API Key。

  3. Base URL 填写 https://agentrouter.org/v1。

  4. Model ID / Model Name 可选：gpt-5.5、glm-5.2

  5. 保存并测试：先发送“只回复 OK”；再发送“请查看当前工作区文件，说明是否存在 README.md，不要修改文件”。

在Roo Code中使用AgentRouter ​

在VS Code中安装Roo Code ​

  1. 在 VS Code Extensions 中搜索 Roo Code 并安装。

  2. 访问 https://agentrouter.org/console/token ，获取你的 API Key

  3. 打开 Roo Code 面板，进入 API Configuration / Provider / Profile 设置。

配置方法一：Claude Opus 系列（推荐优先使用） ​

  1. Provider 选择 Anthropic。

  2. 勾选 Use custom base URL。

  3. Custom Base URL 填写 https://agentrouter.org。注意这里不需要加 /v1。

  4. API Key 填写你获取的 API Key。

  5. 当前 Roo Code 的 Opus 系列模型选择 Claude-opus-4-6。

  6. 保存后先发送“只回复 OK”测试连通性，再测试读取当前工作区文件。

配置方法二： OpenAI Compatible ​

  1. Provider 选择 OpenAI Compatible。

  2. Base URL 填写 https://agentrouter.org/v1。

  3. API Key 填写你获取的 API Key。

  4. Model / Model ID 可选：gpt-5.5、glm-5.2。

  5. 保存并测试：先发送“只回复 OK”，再测试读取当前工作区文件。

在Kilo Code中使用AgentRouter ​

在VS Code中安装Kilo Code ​

  1. 在 VS Code Extensions 中搜索 Kilo Code 并安装。

  2. 访问 https://agentrouter.org/console/token ，获取你的 API Key

  3. 打开 Kilo code 面板，进入 Settings / API Configuration。

配置方法一：Claude Opus 系列（推荐优先使用） ​

  1. 打开provider界面，点击连接Custom Provider

  2. Provider ID 填 agentrouter；Display Name 可随意填写。

  3. Provider API选择Anthropic Messages。

  4. Base URL 填 https://agentrouter.org/v1，⚠️注意这里需要加 /v1。

  5. API key 填写你获取的的 API Key。

  6. 可选模型包括 claude-opus-4-6、claude-opus-4-8、claude-opus-4-7；最后点击 submit 保存**。**

  7. 先发送“只回复 OK”，再测试读取当前工作区文件。

配置方法二： OpenAI Compatible ​

  1. Provider ID填agentrouter；Display Name可随意填写。

  2. Base URL 填写 https://agentrouter.org/v1。

  3. Provider API选择OpenAI Compatible

  4. API Key 填写你获取的 API Key。

  5. Model / Model ID 可选：gpt-5.5、glm-5.2。

  6. 保存并测试：先发送“只回复 OK”，再测试读取当前工作区文件。

二、CLI / 终端类 Harness ​

Claude Code CLI ​

配置参数 ​

配置项填写内容 / 说明
ANTHROPIC_AUTH_TOKEN你的 AgentRouter API Key。Claude Code 会把该值作为 Bearer Token 发送。
ANTHROPIC_BASE_URLhttps://agentrouter.org
ANTHROPIC_MODEL默认claude-opus-4-6，也可以选择claude-opus-4-8和claude-opus-4-7。
Base URL 规则Claude Code CLI 走 Anthropic-compatible 配置，Base URL 不加 /v1。不要与 OpenAI Compatible 的 https://agentrouter.org/v1 混用。

安装与配置步骤 ​

  1. 确认 Node.js：Claude Code npm 包要求 Node.js 18 或更高版本。
node --version
  1. 安装 Claude Code CLI：使用 npm 全局安装官方包。
npm install -g @anthropic-ai/claude-code@latest
  1. 检查安装结果：确认 claude 命令可用。
claude --version
  1. 设置 AgentRouter 环境变量：macOS / Linux 使用 export；Windows PowerShell 使用 $env:。
# macOS / Linux
export ANTHROPIC_AUTH_TOKEN="AgentRouter API Key"
export ANTHROPIC_BASE_URL="https://agentrouter.org"
export ANTHROPIC_MODEL="claude-opus-4-6"
# Windows PowerShell
$env:ANTHROPIC_AUTH_TOKEN="AgentRouter API Key"
$env:ANTHROPIC_BASE_URL="https://agentrouter.org"
$env:ANTHROPIC_MODEL="claude-opus-4-6"
  1. 启动并测试：先测试连通性，再测试只读目录能力。首次启动时如果提示是否使用环境变量中的 API Key，请确认使用。
claude
# 输入：只回复 OK
# 再输入：列出当前目录下的文件，并说明是否存在 README 文件，不要修改文件
✅ 验证建议：OK 测试通过后，再验证读取项目文件、创建临时测试文件和执行简单命令。
⚠️ 注意：如果曾经登录过 Claude Pro / Max / Team 账号，环境变量可能会覆盖订阅登录；如需恢复订阅登录，请在当前终端 unset ANTHROPIC_AUTH_TOKEN、unset ANTHROPIC_BASE_URL、unset ANTHROPIC_MODEL 后重新启动 claude。

OpenCode ​

安装与配置步骤 ​

1. 进入项目目录：建议在一个测试项目目录中配置和启动。

# macOS / Linux
cd ~/Desktop/my-project
# Windows PowerShell
cd $HOME\Desktop\my-project
  1. 安装 OpenCode：Windows 用户可用 npm 安装。
# macOS / Linux
curl -fsSL https://opencode.ai/install | bash
# Windows / 已安装 Node.js
npm install -g opencode-ai
  1. 检查安装结果：确认 opencode 命令可用。
opencode --version
opencode --help
  1. 创建 opencode.json：在项目目录创建配置文件。下面两段二选一，把其中一段写入 opencode.json（不要带 // 注释行）。
// ===== Anthropic（claude-opus 系列）=====
{
"$schema": "https://opencode.ai/config.json",
"provider": {
"agentrouter": {
"npm": "@ai-sdk/anthropic",
"name": "AgentRouter (Anthropic)",
"options": {
"baseURL": "https://agentrouter.org"
},
"models": {
"claude-opus-4-6": {
"name": "claude-opus-4-6"
}
}
}
},
"model": "agentrouter/claude-opus-4-6"
}

// ===== OpenAI Compatible（gpt-5.5 / glm-5.2）=====
{
"$schema": "https://opencode.ai/config.json",
"provider": {
"agentrouter": {
"npm": "@ai-sdk/openai-compatible",
"name": "AgentRouter (OpenAI Compatible)",
"options": {
"baseURL": "https://agentrouter.org/v1"
},
"models": {
"gpt-5.5": {
"name": "gpt-5.5"
}
}
}
},
"model": "agentrouter/gpt-5.5"
}
  1. 登录 Provider：保存 AgentRouter API Key。
opencode providers login --provider agentrouter

6. 启动并测试：先测试 OK，再测试读取目录。

opencode
# 输入：只回复 OK
# 再输入：列出当前目录下的文件，并说明是否存在 README 文件

Hermes Agent ​

安装与配置步骤 ​

  1. 打开终端：macOS / Linux 使用 Terminal；Windows 使用 PowerShell。

  2. 安装 Hermes：Windows PowerShell 安装器存在，但较重。

# macOS / Linux
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
# 如果已安装 pipx，也可以
pipx install hermes-agent
# Windows PowerShell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
  1. 检查安装结果：确认 hermes 命令可用。
hermes --version
hermes --help
  1. 运行模型配置向导：按向导填写 AgentRouter Provider。
hermes setup model
  1. 创建自定义 provider extension

{
id: "claude-opus-4-6",
name: "Claude Opus 4.6 via AgentRouter",
reasoning: false,
input: ["text"],
cost: { input: 0, output: 0, cacheRead: 0, cacheWrite: 0 },
contextWindow: 1000000,
maxTokens: 8192
}
]
});
}

// ===== OpenAI Compatible（gpt-5.5 / glm-5.2）=====
export default function (pi: ExtensionAPI) {
pi.registerProvider("agentrouter-openai", {
name: "AgentRouter openai",

models: [
{

reasoning: false,
input: ["text"],
cost: { input: 0, output: 0, cacheRead: 0, cacheWrite: 0 },
contextWindow: 1000000,
maxTokens: 8192

]
});
}

Pi ​

⚠️：Pi 官方 install.sh 为 POSIX 脚本，当前没有 Windows 原生 install.ps1 路径。

安装与配置步骤 ​

  1. 安装 Pi：Windows 用户建议在 WSL / Ubuntu 中执行。
# macOS / Linux / WSL Ubuntu
curl -fsSL https://pi.dev/install.sh | sh

pi --version
pi --help

mkdir -p ~/.pi/agent
nano ~/.pi/agent/models.json

// ===== Anthropic（claude-opus 系列）=====
{
"providers": {
"agentrouter": {
"baseUrl": "https://agentrouter.org",
"api": "anthropic-messages",
"apiKey": "$AGENTROUTER_API_KEY",
"models": [
{ "id": "claude-opus-4-6", "name": "claude-opus-4-6" }
]
}
}
}

// ===== OpenAI Compatible（gpt-5.5 / glm-5.2）=====
{
"providers": {
"agentrouter": {
"baseUrl": "https://agentrouter.org/v1",
"api": "openai-completions",
"apiKey": "$AGENTROUTER_API_KEY",
"models": [
{ "id": "gpt-5.5", "name": "gpt-5.5" }
]
}
}
}
  1. 设置 Key 并启动
export AGENTROUTER_API_KEY="你的 AgentRouter API Key"
pi
# 选择 agentrouter/claude-opus-4-6 或 agentrouter/gpt-5.5

6.** 测试**：先输入“只回复 OK”，再输入“列出当前目录下的文件，并说明是否存在 README 文件”。

**⚠️注意：**Windows 用户建议通过 WSL / Ubuntu 部署；不要直接在 PowerShell 中执行 POSIX install.sh。

三、IDE / 桌面端型 Harness ​

Trae ​

**⚠️ 登录要求：**Trae 下载和安装后需要先登录；直接选择个人用户登录即可。登录本身不影响 AgentRouter 接入，但不登录时 Model 设置和 Add Model 入口不可用。

配置参数 ​

配置项填写内容 / 说明
入口Settings → Models → Add Model → Custom Config
Opus 系列 API FormatAnthropic Messages
Opus 系列 Custom Request URLhttps://agentrouter.org
Opus 系列 Model ID 示例claude-opus-4-6、claude-opus-4-7、claude-opus-4-8
Gpt与其他兼容系列模型API FormatOpenAI Completions
Gpt与其他兼容系列模型 Custom Request URLhttps://agentrouter.org（Full URL 关闭时由 Trae 自动拼接路径，不要加 /v1）
Gpt与其他兼容系列 模型Model ID 示例gpt-5.5、glm-5.2
API Key你的 AgentRouter API Key

安装与配置步骤 ​

  1. 下载安装 Trae：从 Trae 官网下载对应系统安装包并完成安装。

  2. 登录 Trae：首次启动后选择个人用户登录。登录后才能进入可用的模型配置入口。

  3. 打开模型设置：进入 Settings，左侧选择 Models。

  4. 添加模型：点击 Add Model，并切换到 Custom Config。

  5. 选择 API Format：如果接入 claude-opus 系列，API Format 选择 Anthropic Messages；如果接入 gpt-5.5、glm-5.2，API Format 选择 OpenAI Completions。

  6. 填写 Custom Request URL：填写 https://agentrouter.org。不要在末尾加斜杠。

  7. **填写 Model ID：**Opus 系列可填 claude-opus-4-6、claude-opus-4-7 和claude-opus-4-8；OpenAI Completions 类可填 gpt-5.5和 glm-5.2。

  8. 填写 API Key 并保存：填写你的 AgentRouter Key，然后点击 Add Model 保存。

  9. 验证连通性：在 Trae 对话中发送“只回复 OK”。如果返回 OK，说明模型接入成功。
