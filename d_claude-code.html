在 Claude Code 中使用 AgentRouter ​

Claude Code CLI 走 Anthropic-compatible 配置，Base URL 不加 /v1。不要与 OpenAI Compatible 的 https://agentrouter.org/v1 混用。

配置参数 ​

配置项填写内容 / 说明
ANTHROPIC_AUTH_TOKEN你的 AgentRouter API Key。Claude Code 会把该值作为 Bearer Token 发送。
ANTHROPIC_BASE_URLhttps://agentrouter.org
ANTHROPIC_MODEL默认 claude-opus-4-6，也可以选择 claude-opus-4-8 和 claude-opus-4-7。

安装与配置步骤 ​

1. 确认 Node.js ​

Claude Code npm 包要求 Node.js 18 或更高版本。

bash
node --version

2. 安装 Claude Code CLI ​

bash
npm install -g @anthropic-ai/claude-code@latest

3. 检查安装结果 ​

bash
claude --version

4. 设置 AgentRouter 环境变量 ​

bash
# macOS / Linux
export ANTHROPIC_AUTH_TOKEN="AgentRouter API Key"
export ANTHROPIC_BASE_URL="https://agentrouter.org"
export ANTHROPIC_MODEL="claude-opus-4-6"
powershell
# Windows PowerShell
$env:ANTHROPIC_AUTH_TOKEN="AgentRouter API Key"
$env:ANTHROPIC_BASE_URL="https://agentrouter.org"
$env:ANTHROPIC_MODEL="claude-opus-4-6"

5. 启动并测试 ​

先测试连通性，再测试只读目录能力。首次启动时如果提示是否使用环境变量中的 API Key，请确认使用。

bash
claude
# 输入：只回复 OK
# 再输入：列出当前目录下的文件，并说明是否存在 README 文件，不要修改文件

TIP

OK 测试通过后，再验证读取项目文件、创建临时测试文件和执行简单命令。

WARNING

如果曾经登录过 Claude Pro / Max / Team 账号，环境变量可能会覆盖订阅登录；如需恢复订阅登录，请在当前终端 unset ANTHROPIC_AUTH_TOKEN、unset ANTHROPIC_BASE_URL、unset ANTHROPIC_MODEL 后重新启动 claude。
