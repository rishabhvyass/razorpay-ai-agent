在 OpenCode 中使用 AgentRouter ​

OpenCode 通过 opencode.json 配置 Provider，支持 Anthropic（Claude Opus 系列）与 OpenAI Compatible（gpt-5.5 / glm-5.2）两类，二选一写入即可。

安装与配置步骤 ​

1. 进入项目目录 ​

建议在一个测试项目目录中配置和启动。

bash
# macOS / Linux
cd ~/Desktop/my-project
powershell
# Windows PowerShell
cd $HOME\Desktop\my-project

2. 安装 OpenCode ​

bash
# macOS / Linux
curl -fsSL https://opencode.ai/install | bash

# Windows / 已安装 Node.js
npm install -g opencode-ai

3. 检查安装结果 ​

bash
opencode --version
opencode --help

4. 创建 opencode.json ​

在项目目录创建配置文件。下面两段二选一，把其中一段写入 opencode.json。

Anthropic（claude-opus 系列）：

json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "agentrouter": {
      "npm": "@ai-sdk/anthropic",
      "name": "AgentRouter (Anthropic)",
      "options": {
        "baseURL": "https://agentrouter.org"
      },
      "models": {
        "claude-opus-4-6": {
          "name": "claude-opus-4-6"
        }
      }
    }
  },
  "model": "agentrouter/claude-opus-4-6"
}

OpenAI Compatible（gpt-5.5 / glm-5.2）：

json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "agentrouter": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "AgentRouter (OpenAI Compatible)",
      "options": {
        "baseURL": "https://agentrouter.org/v1"
      },
      "models": {
        "gpt-5.5": {
          "name": "gpt-5.5"
        }
      }
    }
  },
  "model": "agentrouter/gpt-5.5"
}

5. 登录 Provider ​

保存 AgentRouter API Key。

bash
opencode providers login --provider agentrouter

6. 启动并测试 ​

bash
opencode
# 输入：只回复 OK
# 再输入：列出当前目录下的文件，并说明是否存在 README 文件
